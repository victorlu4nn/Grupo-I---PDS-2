# Grupo PDS2

Nesse projeto, iremos desenvolver uma Engine de Jogos do Tabuleiro. Criaremos uma divisão de tarefas, cronograma de objetivos de atividades para cada membro e para o grupo como um todo.

## Objetivo
O projeto terá como objetivo o desenvolvimento de uma engine que forneça uma infraestrutura básica para a criação de jogos de tabuleiro, particionando em uma estrutura geral do sistema e a aplicação de regras específicas de cada jogo. Como problema inicial, temos a identificação das funcionalidades que serão requisitadas em qualquer jogo de tabuleiro - exercendo o papel de sistema geral - e o alinhamento de objetivos e funcionalidades entre o sistema geral e as regras/jogabilidade específica do jogo de tabuleiro. Desse modo, iremos utilizar funções e classes para organizar os jogos catalogados e suas seleções específicas, a organização e armazenamento das regras específicas de cada jogo, controle do tabuleiro e de suas dimensões, controle do status do jogo e dos sistema de turnos e também de controle do jogador e suas informações. 

A motivação de escolha do tema foi a possibilidade de aplicar todos os conteúdos aprendidos ao longo da disciplina em um contexto de desenvolvimento de infraestrutura de jogos, além da criação e aplicabilidade em exemplos de jogos de tabuleiros reais.
