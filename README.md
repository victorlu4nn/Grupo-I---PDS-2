# Grupo PDS2

Nesse projeto, iremos desenvolver uma Engine de Jogos do Tabuleiro. Criaremos uma divisão de tarefas, cronograma de objetivos de atividades para cada membro e para o grupo como um todo.

## Objetivo
O projeto terá como objetivo o desenvolvimento de uma engine que forneça uma infraestrutura básica para a criação de jogos de tabuleiro, particionando em uma estrutura geral do sistema e a aplicação de regras específicas de cada jogo.
