# Grupo PDS2

Nesse projeto, iremos desenvolver uma Engine de Jogos do Tabuleiro. Criaremos uma divisão de tarefas, cronograma de objetivos de atividades para cada membro e para o grupo como um todo.

## Planejamento
Para o planejamento do projeto, começaremos com o desenvolvimento de User Stories e cartões CRC. Eles serão úteis para alinharmos quais os objetivos que buscamos obter com o projeto, quais as funcionalidades esperadas e desejadas, permitir que o grupo esteja alinhado e permitindo discussões e sugestões. As User Stories e os Cartões CRC desenvolvidos estão localizados na pasta /docs. [Ver User Stories](/docs/USER_STORIES.md) [Ver CRC Cards](/docs/CRC_CARDS.md)
